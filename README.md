# Hide/Show Trade Levels

Hide/Show Trade Levels is a custom MetaTrader script that toggles the visibility of trade levels on the current chart of the MetaTrader platform. It was coded by EarnForex.com for MT4 and MT5.

It's a very simple script whose main purpose is to fix MetaTrader's interface that doesn't allow to quickly hide or show trade levels on the chart.

You can find more information about this custom MetaTrader script here: https://www.earnforex.com/metatrader-scripts/hide-show-trade-levels/

Enjoy decluttered charts with a hotkey of your choice!
